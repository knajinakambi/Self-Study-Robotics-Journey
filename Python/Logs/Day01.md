Cause of the Problem

The issue was caused by the space in the file name.
The command prompt could not correctly interpret the file path because of the space.

⸻

Solution

I learned that using double quotation marks (” “) around the file path allows the command prompt to correctly recognize file names with spaces.

⸻

Key Lesson

File naming is important when working with programming tools.
Special characters like spaces can cause errors if not handled properly.
